## 🔄 Simple Personalization & Customization

### 1. Replacing the Avatar Photo
When you have a preferred personal headshot:
1. Save your photo in PNG format.
2. Name it `manik_avatar.png`.
3. Copy it into the folder `c:\Users\manik\Downloads\Portfolio Website`, overwriting the existing placeholder asset. The circular frame and glow elements will adapt instantly!

### 2. Free Cloud Hosting Options
To publish your portfolio to the world for free, you have three incredibly easy choices:

#### Option A: GitHub Pages (Recommended)
Since you already have a GitHub account (`manik305`):
1. Create a new public repository named `manik305.github.io` (replace `manik305` with your exact GitHub username if different).
2. Push the files (`index.html`, `style.css`, `script.js`, `manik_avatar.png`, `ml_suite_project.png`) directly to the `main` branch.
3. Your portfolio will go live instantly at `https://manik305.github.io/`!

#### Option B: Vercel (One-Click)
1. Go to [Vercel.com](https://vercel.com) and link your GitHub account.
2. Import the portfolio repository.
3. Vercel will automatically detect the static landing page and deploy it with a secure SSL certificate, providing you with a custom `.vercel.app` link or connecting to your custom domain.
